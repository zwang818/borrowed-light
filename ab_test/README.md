# A 地图 × B 战斗独立整合

打开 `res://ab_test/ab_combat.tscn`，运行当前场景（F6 / Fn+F6）。F5 仍进入原主场景。

## 操作与验收路线

- WASD / 方向键移动，鼠标瞄准。
- 小一从地图底部出生，初始无武器，点击左键不会攻击。
- 沿 A 的通路向上，抵达狭口中的青色枪模型。距离不超过 40 像素、无遮挡时按 E 拾取。
- 拾取后左键点按蓄力 0.8 秒，蓄力结束时取鼠标方向并执行原有 ±10° 索敌。激光逐渐伸出，碰墙、敌人或地图边界停止延伸，不反射；首次碰墙或敌人后 0.15 秒消失，未命中最多持续 0.5 秒。发射声为更尖锐的短促 biu。
- 第一战斗区一台清扫者，出口战斗区两台。沿用 B 的血量、追踪、前方攻击预警和伤害规则。
- R 回出生点并恢复双方生命，清扫者归位；已经取得的枪保留。重新启动场景才回到未拾取状态。

小一直接复用标题右下角的机器人 SVG，身体保持直立，武器独立朝向鼠标。新枪和清扫者使用配套的蓝灰金属、冷色能量条、暖色传感器造型，以代码绘制，可修改 `combat_skin.gd`。这些替换只影响此整合场景，B 的原测试入口保持原样。
