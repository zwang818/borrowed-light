# AB 战斗声音快照

经用户明确要求，从 B 灰盒同步当前音效（2026-10-21）。脚步为四种格栅冲击/摩擦/零件轻碰变化，-22 dB；其他声沿用 B 当前设置。

WAV 由 Codex（OpenAI AI 编程助手）编写 generate_sounds.py 后通过数学合成生成，为原创原型占位声音，无第三方录音、采样或署名要求。保留生成脚本可复现。

独立复制资产与播放组件，之后修改 B 不会自动影响 AB。脉冲蓄力与激光继续使用既有共享资源，本轮未改。AB 接入玩家移动、受伤、死亡、拾枪以及三台清扫者预警、攻击、受击、停机；未放入的哨机/Boss/散射/机关声音仅保留资源，不增加玩法。

每个敌人的预警按独立来源管理，取消其中一个不会停止其他敌人的预警。死亡、暂停与重试清理声音，不补播。

最新脉冲枪同步：pulse_biu.wav 为 180 ms 尖锐降调合成音，来源为 Codex 编写 generate_pulse_biu.py，无第三方采样。pulse_charge.wav 为原项目合成蓄力声音的独立副本。同步武器参数：蓄力 0.8 秒，命中敌人/墙壁后 0.15 秒消失。
