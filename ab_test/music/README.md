# AB 内部探索背景音乐

按用户要求同步 B 当前音乐快照，32 秒循环，默认 -24 dB，任一清扫者预警或玩家受伤时压低至 -32 dB；死亡 0.3 秒淡出，重试 0.8 秒淡入，暂停保留播放位置。独立复制资源和脚本，未来 B 改动不自动同步。未修改地图、主入口或共享战斗脚本。

来源：Codex（OpenAI AI 编程助手）编写 generate_music.py，以数学振荡器及包络合成的原创原型占位音乐。无第三方采样、录音或署名要求，不是实录乐器或商业成品配乐。可运行同目录生成脚本重建 WAV。

检查入口：godot --headless --path . --script res://ab_test/music_check.gd。覆盖三个清扫者分别预警、受伤压低、暂停恢复、死亡停止、重试和清理；听感需人工试听。
