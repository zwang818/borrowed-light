# 脉冲枪原型音效

pulse_charge.wav：1 秒上升音高蓄力音。
pulse_laser.wav：1 秒激光振荡音，带起落淡化。

两份均为本项目通过数学振荡器原创合成的单声道 44.1 kHz / 16 bit PCM，无第三方采样或署名依赖。可由 D 后续替换。
播放组件位于 scenes/weapons/pulse_audio.gd，监听武器状态；暂停随场景冻结，取消或结束时停止，不控制战斗逻辑。

## 脉冲 biu 音效

pulse_biu.wav 为 Codex 编写 generate_pulse_biu.py 数学合成的原创占位声音，无第三方采样/录音。180 ms 快速降调，发射时播放一次、不循环，取消或结束时仍由既有监听器停止。当前 B 使用此声音，AB 快照继续引用 pulse_laser.wav，不覆盖旧资源。

最新试听调整：biu 起始频率提高至约 2460 Hz，并增加少量二、三次谐波，使声音更尖锐；时长和归一化峰值保持不变，不单纯提高音量。仅 B 使用。

## 图纸传输

`blueprint_transfer.wav` 为用户选定的「扫描脉冲」原创合成版，单声道 44.1 kHz / 16 bit PCM，无第三方采样。总长 5 秒。数据流在接口接近扣合时渐入，持续到传输结束前淡出，4.25 秒起播放完成提示，对应腹腔图纸台的插入、传输和收回动画。

## 腹腔主曲《余温》

`abdomen_residual_warmth.wav` 是用户选定的 A 版「空置厂房」，由 Codex 为本项目原创合成，无第三方采样或署名依赖。76 BPM、D–F–E 动机，全曲 88.42 秒，游戏内使用 24 kHz / 16 bit 立体声 WAV 并整段循环。

打开 `scenes/gameplay/abdomen_level.tscn` 按 F6 即可试听。加载揭开后开始播放，随设置中的「音乐」音量变化。神明演出显示时压低音乐，结束后恢复。出口转场视频接管声音时暂停主曲。

## 腹腔 Boss 曲《并联处置》

`abdomen_parallel_engagement.wav` 为 Codex 原创合成的配乐，无第三方录音或采样。108 BPM、71.11 秒循环，游戏内为 24 kHz / 16 bit 立体声 WAV。两台出口清扫者停机并开始合体时切入，Boss 停机或小一死亡时淡出并回到《余温》。在门外重试后，重新触发合体时从头开始播放；音量使用现有「音乐」设置。

## 腹腔小一脚步

`footsteps/` 中的四段 `xiaoyi_steel_*.wav` 是用户选定的 A 版「轻踩钢板」，由 Codex 为本项目原创合成，无第三方录音或采样。44.1 kHz / 16 bit 单声道，每次触地约 105 毫秒，左右脚交替播放四个轻微变化的落脚声。

第一关正式场景按小一的实际步行距离播放。正常满速时约每 0.25 秒一步，按住 Shift 加速时约每 0.20 秒一步。原地、顶墙、暂停和管道传送本身均不产生脚步。

并联清扫者开始合体时，脚步音量额外降低 8 dB。战斗结束或回到门外重试时恢复。
