2026-10-27。仅用于当前腹腔地图，可逐件替换。冷灰绿旧金属、废弃制造设备、墙角蛛网与冷白工作灯；不包含机器人、敌人、武器或 UI 素材。

## 来源与使用记录

环境 PNG 由本次 Codex 内置 ImageGen 生成，依据用户在本对话认可的腹腔像素概念图进行材质及环境物件设计。没有下载或混入第三方素材包。用户提供的概念图本身未作为地图背景或可发布素材拷入工程。

AI 生成素材记录为项目环境美术初版，不把它们标成第三方 CC0 素材，也不据此声称独占版权或完成最终发行审查。保留独立源图，后续可以在像素编辑器中逐格重绘。

| 文件 | 使用方式 |
| --- | --- |
| `terrain_atlas.png` | 4×4 等分的地板、格栅、警戒漆与墙面材质；第一排二次生成，减少地面颗粒和重复裂纹 |
| `props_atlas.png` | 4×4 等分的透明环境物件图集；通过 `abdomen_prop.gd` 选格绘制，不改原图 |
| `welding_station_parts.png` | 2×2 透明分件：左上固定台面、右上上臂、左下前臂及焊头、右下轴盖；用于出生区左侧自动焊接设备 |
| `compressor_parts.png` | 压缩机固定机身、转子、左右活塞和固定防护罩；按脚本内独立区域取样，保留完整源图 |
| `fleeing_spider.png` | 2×2 四帧透明蜘蛛步态，含腿显示约 20 世界单位 |
| `service_cavity_clean.png` | 去除背景蛛网的补底候选；仅采样 9 个网区域，未整图替换旧背景 |
| `service_cavity.png` | 无法行走区域中的暗管线、巨型机械肋骨背景；在地面后重复铺设 |

PNG 实际为 1254×1254；4×4 图集单格为 313.5 源像素，机械臂 2×2 分件图单格为 627 源像素。代码按图片真实尺寸计算裁切，不将图集尺寸当作正式 TileSet 规格。素材导入使用无损、无 mipmap，环境节点采用最近邻过滤，部分设备与地面使用局部像素整理材质；独立蛛网和蜘蛛直接按各自图集取样，角色和界面不使用环境材质。

## 生成提示摘要

- 共用方向：俯视角像素游戏、废弃巨兽腹腔制造区、灰绿氧化钢与石墨灰、低饱和锈迹、冷白光，无角色／枪械／标题／路径箭头。
- 材质图集：严格四行四列，平整可拼接地板、工业格栅、褪色警戒漆、墙顶板与检修面板；地板中心留白，磨损集中边缘。
- 物件图集：透明背景、严格四行四列、单元间不重叠、旧仪器碎屏与外露电缆、可读的机械结构、少量蛛网，不画互动对象或新敌人。
- 管线背景：深色竖向巨管、机械肋骨支架、夹箍和废弃线路，作为地板外的非行走背景。

当前只是一张地图的可调整美术方向。32 世界单位的灰盒格、角色占地、摄像机与工程分辨率均未更改，OPEN-01 整套正式美术规格仍未定稿。
