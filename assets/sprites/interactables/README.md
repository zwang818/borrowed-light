# C 交互设施贴图

2026-11-02，按用户“门与终端贴合游戏画风”的请求，使用内置 image_gen 分别生成两张原始透明 PNG，保留原始像素和透明通道，未从截图提取图片。

- `bulkhead.png`：灰绿锈蚀金属双扇门；Godot 按中心缝裁切绘制两片，开门时缩回，不拉伸动画帧冒充开门。
- `access_terminal.png`：斜面屏幕、键盘、铆钉与立柱；屏幕状态由 C 叠加绘制，区分锁定、可用和完成。
- 由 `scenes/gameplay/facility_visual.gd` 消费，用途为 2D 可动模型，未添加 3D 网格或插件依赖。
- 运行时使用现有 A 像素颗粒材质换算，以当前腹腔 1 个美术像素约 1 世界单位为试做基准；不裁定全项目最终规格。
- 原始 PNG、必要 `.import` 一并保留；生成缓存、预览图和截图不纳入工程。

生成方式：内置 image_gen；完整提示词、原图 SHA-256 和用途见 [generation_source.json](generation_source.json)。这是本项目生成素材，未声称为第三方 CC0 素材。

提示词要点：俯视角工业废土像素风、灰绿铁壳、少量铁锈与黄铜、透明背景；门中央缝便于拆分运动，终端预留暗屏用于实时状态。角色、地板、墙和井盖图集继续使用原项目资源。
