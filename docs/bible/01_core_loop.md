# 01 · Core Loop（核心循环与关卡）

> 统一 Bible v2.1 · 2026-10-18 · 当前执行版本。强制规则、建议方案和待定项分别标注。

[返回总览](_index.md) · [待定与决策](99_decisions.md)

## 1. 强制循环与节奏

### LOOP-01 · 循环不可偷换

照亮未知 → 保存空间记忆 → 探索 → 战斗或机关 → 操作终端 → 打开下一段 → Boss → 同步。不能简化成纯射击竞技场，也不能只做剧情步行而删除战斗与探索。

### LOOP-02 · 场景顺序

| 场景 | 必须承担的内容 | 时长预算 |
| --- | --- | --- |
| 荒原 / `wasteland` | 见闻、求救、移动交互教学；结尾复用 | 开头结尾合计 1–2 分钟 |
| 腹腔 / `abdomen` | 照明记忆、出生地、脉冲枪、清扫者、接口伏笔 | 2–3 分钟 |
| 脊柱 / `spine` | 机关、哨机、短协议体验、散射工具、近路与隐藏线索 | 约 3 分钟 |
| 胸腔 / `thorax` | 敌人简单组合、供电恢复、主动营救决定 | 2–3 分钟 |
| 核心 / `core` | Boss、同步、转场结尾 | 2–3 分钟 |

允许每关由多个子场景组成，不把“五个主要场景”误写成只能有五个 `.tscn`。每关两三个小房间是布局起点，具体布局可在预算内灰盒调整。

### LOOP-03 · 教学和支路

必须先教会基础移动、照明、射击和预警识别，再组合使用。不得把新机关、新敌人与看不清的危险叠在首次教学。必要武器及主线事件在必经路；支路少量提供补给或记录，不以收齐日志开主线门。时长超预算先减少重复路线和等待，不缩短到来不及反应的预警。

## 2. 玩家动机

- 直接目标：抵达意识核心，带神明离开。
- 短期目标：找到出口、解决眼前敌人或机关、启动明确终端。
- 探索动机：获得补给、发现路线与阅读世界记录。
- 情感动机：回应神明对外界的好奇，逐步形成陪伴关系。

必要武器始终位于必经路。支路不承担通关必需品，隐藏记录不作为开门收集数量条件。

## 3. 循环尺度

| 尺度 | 玩家做什么 | 获得的反馈 |
| --- | --- | --- |
| 短时行动 | 移动、瞄准、看预警、攻击、躲避 | 灯光变化、命中、敌人恢复窗口 |
| 房间循环 | 看清地形、解决阻碍、启动终端 | 记录空间、开门、恢复固定照明 |
| 关卡循环 | 沿主线推进，选择少量支路 | 新武器、补给、关系发展、可选日志 |
| 完整流程 | 营救创造者并离开 | 温情收束；可被重新理解的结局 |

## 4. 教学编排建议

1. 荒原安全区学习移动、靠近与交互。
2. 制造区先体验照亮和记忆，再拿枪练习射击。
3. 单个清扫者教会保持距离、观察停顿预警。
4. 输能区独立短段教学周期机关，再引入哨机弹丸。
5. 检修终端激活协议，体验绕过清扫者与授权门。
6. 获得散射工具，学习近距离输出取舍。
7. 胸腔少量组合运用，Boss 检验移动、预警与输出时机。

教学首次出现时给出短提示；长对话安排在安全位置。不要把新机关、新敌人与黑暗同时作为第一次考验。

## 5. 回报与反馈

| 行为 | 回报 | 必须可见的反馈 |
| --- | --- | --- |
| 探索新区域 | 静态空间记忆 | 地形由未知变为当前可见，离开后仍有轮廓 |
| 启动维修终端 | 路径推进或区域灯光恢复 | 终端、门或场景灯实际变化 |
| 战胜敌人 | 通过危险区域 | 命中、死亡与威胁结束反馈 |
| 进入支路 | 补给或可选记录 | 能辨认的物件与简短提示 |
| 通过 Boss | 开放同步终端 | 停止攻击、清除残留危险、转入安全交互 |

## 6. 试玩验收

- 请未参与设计的人从新游戏开始，记录完成时长、迷路位置与死亡原因。
- 观察其是否知道当前主目标、是否理解记忆不提供实时敌人位置。
- 不读日志通关一次，检查主线是否独立完整。
- 阅读全部日志通关一次，检查线索是否互相支持且没有直接泄底。
- 如果时间超预算，优先减少重复房间和等待，不压缩必要预警或强制玩家快速读字。


## 7. 下一步验证：样板房间（制作与验收规格）

先做一个可运行的灰盒房间及一个最小相邻落点，用来验证跨房间提交；这不增加正式关卡数量。本次文档修订只规定验证内容，不表示已制作样板。

最小配置：玩家与脉冲枪、照明和空间记忆、一种普通敌人、终端控制门和固定灯、短对话或日志、死亡重试入口。敌人可先用行为已经明确的固定哨机，不以清扫者攻击形式待定阻塞房间贯通。

按以下顺序验收：

1. 灰盒移动、瞄准和射击可用；相邻墙后不被揭图。
2. 终端开门亮灯，只扩大无遮挡可见区域；普通敌人的锁定与发射符合 VISION-04。
3. 取得武器并读内容，开门后在跨房间前死亡：门和灯回基线，武器、探索和已读内容保留；再次操作仍能开门且不重复对白。
4. 成功进入相邻落点后返回：原房间门和灯保持已提交状态；模拟转场失败时不错误提交。
5. HUD 与对话采用覆盖实际中文的字体，不能用仅显示“借光”的结果代替文字界面验收。

这个最小房间不代表全项目验收通过。散射对敌人与 Boss 的逐弹伤害、清扫者丢失视线和协议中断，在对应模块完成后按 QA-05、QA-15 单独验证。记录操作手感、迷路点和重试结果；数值平衡、最终日志和具体关卡布局继续迭代，不必等全部定稿才做灰盒。
