# 02 · Entities（实体与内容清单）

> 统一 Bible v2.3 · 2026-10-27 · 当前执行版本。强制规则、建议方案和待定项分别标注。

本章定义实体职责和制作边界。实体表中的 ID 与 08 命名规范统一；耐久、速度、射程等数值仅在 04 参数表维护，未定项见 99。

## 1. 角色与敌人

| 实体 / ID | 职责 | 行为与状态 | 制作边界 |
| --- | --- | --- | --- |
| 小一 / `player` | 移动、探索、战斗、记录、交互 | 可行动、受伤无敌、死亡；另有协议、已完成进化、已解锁能力与当前复活点 | 一名主角，不做跳跃或连招 |
| 神明 / `deity` | 通讯引导与营救对象 | 通过对话、终端和意识光点出现；指导小一学习、自我改造及首次校准 | 不需要可行走 NPC 或完整配音 |
| 清扫者 / `cleaner` | 近距离施压 | 巡逻→发现→接近→预警→攻击→恢复；死亡退出 | 已确认近身攻击：预警后打击前方短距离区域，不冲撞 |
| 防卫哨机 / `sentry` | 远程预警与躲避教学 | 待机→瞄准预警→发射一组弹丸→恢复 | 固定炮台，不做复杂追击 |
| 核心监护者 / `core_guardian` | 最终战斗 | 待机→攻击预警→攻击→恢复；击败后停机 | 固定中央，两种攻击，不增加额外阶段资产 |

清扫者接受低级维护协议；哨机和 Boss 核验硬件，协议不能骗过。维护系统按旧规则运行，不写成人格化恶人。

## 2. 战斗实体强制规则

### COMBAT-02 · 两种内置攻击能力的职责

脉冲激光能力在腹腔原取枪位置的改造教学点学习：按 E 主动交互，经神明引导完成自我改造、操作练习与校准后解锁，不能靠走过自动获得。发射装置属于小一身体的一部分，不是地面枪械或独立持枪道具。点按左键开始蓄力，蓄力结束时以当前鼠标方向在正负 10° 内辅助索敌并锁定修正方向，随后发射持续激光，起点随玩家移动；不设固定射程上限，遇墙、地图边界或敌人停止延伸，同一束对同一敌人只伤害一次。结束后才能再次点按，不缓存忙碌期间的点击，不因持续按住而自动重复。旧弹丸、弹夹、射击间隔与回满机制取消，时长见 04。散射臂形态在脊柱必经路通过第二次神明引导与手臂自我改造解锁；手臂结构展开为散射发射形态，使用短射程多弹丸，不自动套用激光规则。两种能力不形成升级替代。

切换攻击形态不得绕过攻击时序。脉冲激光不反射；普通弹丸仍只结算一次命中，不默认穿透、反弹或友伤。激光不伤害玩家自身。散射各弹丸可分别命中同一大目标并独立结算伤害；普通敌人和 Boss 没有受击无敌，受击闪烁不得吞掉其他弹丸的伤害。本局已完成进化及其攻击能力在死亡后保留；从已激活的复活点重生后可正常使用，不重播教学、不重新校准，也不生成或拾取实体枪械。死亡期间停止攻击与输入，复活后再恢复控制，详见 STATE-01。

### ENEMY-01 · 清扫者

巡逻 → 发现 → 接近 → 停顿预警 → 前方短距离近身攻击 → 恢复。必须能够接近玩家，允许实现必要的简单绕障；不得把“不做复杂 AI”误解成不追踪玩家。用户已确认采用近身攻击，不增加冲撞。预警开始锁定攻击方向，生效期只对前方显示区域内玩家造成一次伤害，普通接触不扣血。协议状态不可被它作为清除目标锁定。发现、失去视线和协议激活时的状态转换统一遵循 [03_rules.md](03_rules.md) 的 VISION-04；失去有效发现条件立即停止追击与攻击，不使用未定义的追踪宽限时间。

### ENEMY-02 · 哨机

固定炮台，检测有效视野 → 瞄准预警 → 一小组可躲弹丸 → 恢复。无需移动追击，不受低级协议欺骗。只有满足 VISION-04 中玩家可辨认、射程和无遮挡条件时才可锁定与发射；失去条件取消未发射攻击，重新发现后重新完整预警。

### BOSS-01 · 核心监护者

固定中央，有明确血量；只有扇形脉冲和地面清除两种攻击，顺序可学习，每次留恢复窗口。可在低血量略缩短间隔，但不得新增招式、追击或资产阶段。房间有足够可达安全空间，全场应急照明保证攻击可读。

击败后取消预警、攻击计时和残留危险，再开放同步终端。Boss 失败从门前恢复点直接重试，不重走胸腔；战斗中不插入长对白。

## 3. 能力配置职责

| 能力 / ID | 获得位置 | 定位 | 可调配置 |
| --- | --- | --- | --- |
| 脉冲激光能力 / `pulse_gun` | 制造区原取枪点改造教学 | 辅助锁向、蓄力直线激光，遇墙、边界或敌人停止 | 蓄力时长、持续时长、展开时长、索敌角度、单束伤害 |
| 散射臂形态 / `scatter_tool` | 输能区必经路手臂改造教学 | 较短射程、较长间隔、多弹丸，适合近距离集中命中 | 射击间隔、弹速、射程、伤害、弹丸数、散射角 |

脉冲激光能力使用直线射线，散射臂形态使用普通弹丸，不能强行共用弹丸发射流程。均不需要收集弹药；不增加弹夹、装填、品质与元素系统。两种能力不存在升级替代关系。

数字键 1 为激光模式：小一始终抬起自身左臂，左键发射脉冲激光；2 为无武器模式：双手放下，左键不攻击；3 为散弹模式：始终抬起自身右臂，左键发射散弹。两种发射结构属于不同手臂，不再沿用“同一手臂切换”的表述。激光和散弹模式下身体朝向鼠标，无武器模式下身体朝向实际移动方向，停止时保留最后朝向。不可在蓄力、发射或恢复期间切模式绕过时序；正式关卡只允许选择已解锁的攻击能力。无武器是收起攻击的姿态，不是第三种攻击能力。左右视图不得整体镜像交换手臂。

### 改造教学交互流程

1. 原取枪位置改为神明指导的改造教学点，沿用当前 2×2 格占地与稳定位置；不再摆放可拾取枪模型。
2. 首次到达时提示按 E 学习。玩家主动交互后，神明讲解原理，小一回应并进行身体结构调整；长对话和演示期间暂停外部战斗与机关。
3. 教学采用受控练习验证操作，再完成校准。练习阶段只允许教学指定的试射，不提前赋予正常战斗攻击权限，不能伤害暂停中的场景敌人。
4. 首次校准完成后记录进化完成、解锁能力，恢复外部世界并更新目标；在进化点后方安全位置设置对应复活点，完成进化并到达后激活。教学中断不提前发放能力或激活后方复活点；未完成教学可重新开始。
5. 进化完成后的战斗死亡：保留所有已完成进化和已解锁能力，回已激活复活点重生；不再播放已完成的进化、神明教学、演示或练习，不要求再次校准。未学习的能力仍不可用。

表现以原有小一模型的局部机械展开、发光和姿态变化完成，保持两次线性改造的课程规模；不引入材料收集、改造商店或额外分支。

## 4. 投射物与危险

| 对象 | 作用 | 必须提供的信息 |
| --- | --- | --- |
| 玩家投射物 | 命中敌人、墙壁或射程终点 | 清楚的发射与命中反馈 |
| 敌方投射物 | 哨机和 Boss 远程威胁 | 发光、方向与运动轨迹可辨认 |
| 机械压块 | 周期移动或压下伤害 | 攻击区域、动作前预警、安全间隔 |
| 通电地板 | 周期区域伤害 | 未通电、预警、通电三种可区别状态 |
| Boss 地面清除区 | 延迟地面攻击 | 生效前显示危险格，始终留出可达安全区域 |

## 5. 可交互物件

| 对象 / ID 前缀 | 功能 | 状态 |
| --- | --- | --- |
| 检修门 / `door_` | 限制或连接路线 | 锁定、可开启、已开启；记录所需终端或权限 |
| 维修终端 / `terminal_` | 恢复照明或触发路线进度 | 未启动、已启动 |
| 协议终端 / `protocol_` | 指定检修区域内启用协议 | 可用、激活；关联所属区域 |
| 维修点 / `repair_` | 恢复耐久 | 可交互；是否重复使用见 [99_decisions.md](99_decisions.md) 待定项 |
| 改造教学点 / `upgrade_`（旧 `pickup_` ID 保留兼容） | 神明指导首次学习、身体改造、操作练习和校准；完成后不因死亡重做 | 未学习、教学中、进化完成／能力可用 |
| 复活点 / `checkpoint_` | 在脉冲与散射进化点后方提供安全重生位置 | 未激活、已激活；记录所属房间和合法落点 |
| 日志 / `log_` | 阅读可选记录 | 未读、已读；已读仍可回看 |
| 同步终端 / `sync_` | Boss 后触发终局 | 未开放、可同步、已完成 |

终端使用同一交互框架，通过配置调用不同效果。恢复耐久与激活路线属于不同功能，不能因为都叫“维修”而默认合并。

## 6. 场景与共用资产

| 场景 ID | 关键视觉对象 | 共用素材 |
| --- | --- | --- |
| `wasteland` | 神兽外观、天空、缝隙植物 | 结尾复用本场景 |

| `spine` | 输能管、检修通道、蒸汽、弧形图 | 同上 |

| `core` | 圆形隔离装置、Boss、意识光点 | 同上，增加核心专用装饰 |

每个房间需要稳定 `room_id`、入口重试位置、探索区域、出口及可重置对象。每个可持久记录物件需要独立 ID，不能用临时节点路径代替。

## 7. 最小资产清单

- 主角移动、攻击、受伤、死亡反馈；具体动画帧数待定。
- 清扫者移动与攻击预警，哨机瞄准与发射，Boss 两种攻击。
- 脉冲发射结构、散射臂展开／收拢、改造与校准反馈、玩家与敌人弹丸、命中和停机效果。
- 共用机械瓦片、门、终端、维修点与日志标记。
- 荒原背景、神兽外观、核心装置与少量线索图。
- UI 图标、字体、对话样式与基础声音，详见对应章节。

正式绘制前一起确认基准分辨率、瓦片尺寸、角色画布与实际占地、碰撞尺寸、像素缩放和过滤方式，见 OPEN-01；当前不把临时灰盒图形视为最终资产。
