# 05 · UI / HUD（界面与操作）

> 统一 Bible v2.1 · 2026-10-18 · 当前执行版本。强制规则、建议方案和待定项分别标注。

[返回总览](_index.md) · [待定与决策](99_decisions.md)

## 1. 强制规则

### COMBAT-01 · 操作基准

WASD / 方向键移动，鼠标瞄准，左键攻击，1 / 2 切换已获武器，E 交互和推进对话，M 记忆界面，Esc 关窗或暂停。移动与瞄准独立，斜走不得更快。没有灯光资源管理或额外协议切换键。

### UI-01 · 信息只反映真实规则

HUD 提供耐久、当前武器、当前目标、交互、通讯、Boss 血量和协议提示；布局可为可读性调整。不得增加不存在的弹药、电量、真相进度或敌人雷达。日志未发现条目不能泄露标题和全文。

记忆界面只有已探索地图、已读日志两页；地图显示已发现出口、维修点、终端及导航所需信息，不提前显示隐藏房间或实时敌人。基础菜单必须支持开始、暂停恢复、死亡重试和返回标题；未做的功能不能放可点击假按钮。

### ART-01 · 视觉基准

像素风，环境暗灰铁锈和低饱和蓝，主角与神明暖色，维护系统冷白青色与规则图形。已探索轮廓区别于当前照亮空间；危险以亮度和形状共同提示。中文不能缺字、截断或超框。

基准分辨率、瓦片尺寸、角色画布与实际占地、碰撞尺寸、像素缩放和过滤方式必须作为一套美术规格确认；确认前只做可替换灰盒，不批量生成最终资产。基础素材复用地板、墙、门、管道和终端，各区域用少量专用装饰区分。

## 2. 输入与 Input Map

| 输入 | 功能 | 建议 Input Map 名称 |
| --- | --- | --- |
| WASD / 方向键 | 移动 | `move_up` / `move_down` / `move_left` / `move_right` |
| 鼠标 | 瞄准 | 读取鼠标世界位置 |
| 鼠标左键 | 当前武器攻击 | `attack` |
| 1 / 2 | 切换已获得武器 | `weapon_1` / `weapon_2` |
| E | 交互、推进对话 | `interact` |
| M | 记忆地图与日志 | `toggle_memory` |
| Esc | 关闭当前窗口或暂停 | `pause` |

基础版不增加灯光开关、协议常驻切换键或闪避键。手柄和改键属于待评估扩展。

## 3. HUD 布局建议

| 位置 | 内容 | 显示规则 |
| --- | --- | --- |
| 左上 | 耐久格 | 持续显示；受伤时短暂强调 |
| 左下 | 当前武器及 1 / 2 提示 | 未获得武器不显示为可用 |
| 右上 | 当前简短目标 | 仅表达玩家已知目标，不泄露真相 |
| 玩家或物件附近 | `E · 操作终端` 等提示 | 只显示当前有效交互对象 |
| 下方中央 | 通讯或对话框 | 说话者、正文、推进提示 |
| 顶部中央 | Boss 血条 | Boss 战期间显示，结束后移除 |
| 耐久附近 | 协议状态 | 激活时显示蓝色图标与文字说明 |

不显示弹药计数、照明电量等不存在的资源。战斗 HUD 应让出中央视野，不遮挡预警和玩家移动路线。

## 4. 记忆界面

只设“地图”和“日志”两页，不增加收集拼图或角色养成页。

### 地图

- 显示已探索的空间轮廓、已发现出口、维修点和终端。
- 未探索区域不画完整结构，不暴露隐藏房间。
- 不显示动态敌人位置。
- 建议显示玩家当前位置及当前所在房间，帮助理解方向。
- 地形记忆与门、终端实际状态分开更新；死亡重置后标记随实际状态改变。
- 图例简短区分出口、维修点、终端，不仅依赖颜色。

### 日志

- 收录已读的四至六条记录，以及必要主线对话摘要。
- 按发现顺序或固定叙事顺序排列，选定一种后统一。
- 未发现记录不显示剧透标题、全文或“真相完成度”。
- 阅读日志不触发自动总结、结局分支或隐藏路线解锁。

**建议**：打开记忆界面时暂停战斗与机关，避免玩家阅读时受伤；该暂停策略尚待小组确认。

## 5. 对话与提示

- 每段以几句为单位，不让玩家在战斗中阅读长文字。
- 安全剧情对话暂停世界；短环境提示与长对话采用不同展示方式。
- 若采用逐字显示，建议第一次 E 显示完整本句，下一次 E 推进。
- 玩家已看过的剧情在死亡重试时不自动重播。
- 交互被锁定时显示简短原因，如“需要恢复供电”，而非无反馈。
- 获取武器时显示名称、按键和用途；不要求玩家记住复杂数值。

## 6. 菜单与界面优先级

建议最小菜单：

- 标题：开始游戏、音量设置、退出。无存档时不显示可用的“继续游戏”。
- 暂停：继续、音量设置、返回标题。
- 死亡：从当前重试点重试、返回标题。
- 结尾：返回标题、退出。

建议同一时间只打开一个主要模态窗口。Esc 优先关闭记忆或设置页，再处理暂停，不能关闭菜单的同时向游戏世界传递交互或攻击。

返回标题会丢失本次对局时，建议明确提示“本次进度不会保存”；这是玩家防误操作提示，不是制作流程审批。

### 当前标题原型（2026-10-20，TITLE-001）

按用户明确要求，主场景保留 `res://scenes/main.tscn` 入口，实例化独立标题场景。画面为低饱和蓝灰荒原、倒下的机械神兽、带暖光的小机器人；淡金立体“借光”标题与左下角低对比英文水印分层编辑。标题引句为“世界的意义，必定在世界之外。”，据维特根斯坦《逻辑哲学论》6.41 英文首句自译，并显示出处。当前几何素材是可替换原型，不将 1280×720 排版参考画布视为整套美术规格定稿。

- 开始游戏：未指定第一关时禁用；配置 `Start Scene` 后启用并切换到指定场景。
- 退出：关闭游戏进程。
- 机器人：轻微待机摆动与暖光呼吸；悬停或聚焦时提亮，点击打开“记忆档案”存档面板。
- 存档面板：当前只显示“尚无存档”，不提供虚假的继续游戏或可读档记录；关闭按钮及 Esc 关闭面板并恢复焦点，弹窗打开时背景按钮退出键盘导航。

这里的“记忆档案”专指标题存档入口，与游戏内 M 键打开的地图／日志记忆界面分开。此次只授权入口及空状态展示，不表示完整存档已完成，也不把跨程序存档加入基础必交付范围。设置、暂停等尚未完成的菜单继续按阶段实现。美术替换与验收步骤见 [标题界面调整说明](../title_screen.md)。

## 7. 视觉细节

- 场景：暗灰、铁锈、低饱和蓝。
- 主角与神明：暖色光和通讯提示。
- 维护系统：冷白、青色、规则化边框。
- 危险提示：高对比亮色配合轮廓、闪烁或形状，不只靠红绿区别。
- 已探索区：低亮度简化轮廓，明显区别于当前可见地形。
- 字体必须覆盖实际使用的简体中文与标点；字体授权记录在资产清单中。
- 已核对项目 [字体说明](../../assets/fonts/README.md)：原 `borrowed_light_title.ttf` 仅含“借光”和基本 ASCII，不能直接承担中文 HUD、对话或日志。2026-10-20 标题原型已新增 Noto Sans SC 菜单子集与 Noto Serif SC 标题子集，覆盖当前标题界面实际文案；仍不代表覆盖全部中文。制作 HUD、对话或日志时须继续补字或使用覆盖所需字符的许可字体。
- 字体验收使用实际目标提示、物件名称、整段对话、日志和中文标点逐项渲染；不能仅凭标题正常或系统偶然回退就判定通过。
- 基准分辨率、像素缩放倍率和字号待美术规格确认；需要实机检查中文可读性。

## 8. 结尾与验收

结尾文字唯一基准见 [_index.md](_index.md) 的 STORY-04，禁止擅自追加解释性文案。

- 第一次游玩不查文档也能找到交互、换武器和地图操作。
- 任意界面关闭后不会误射击或跳过对话。
- 暂停与恢复后危险计时正确；地图不显示过期门状态。
- 中文无缺字、截断或超框，较长日志仍可完整阅读。
- 仅看主线 HUD 和对话不会直接得知隐藏真相。
