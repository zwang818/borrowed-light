## 1. 现有工程与强制边界

### ENG-01 · 继承现有工程

工程根为 `borrowed-light/`，主场景为 `res://scenes/main.tscn`。README 记录 Godot `4.7.2.stable.official.ed1daf0bf`；`project.godot` 声明 4.7、Compatibility。这里只记录仓库事实，未验证所有成员实际安装版本。不得根据旧 Bible 的“版本待定”擅自升级、降级、换渲染器或另建工程。

当前场景主要显示标题，不能声称游戏玩法已经完成。不要为了匹配目录示意图，把已有主场景移成 `scenes/main/main.tscn`。

### ENG-02 · 最小必要结构

复用已有场景和代码；没有相关功能时只创建当前任务需要的模块。玩家负责玩家行为，敌人负责自身战斗，房间负责本地重试，UI 展示状态而不结算伤害。跨场景管理器只保存必要的对局数据，不把所有节点与计时器堆进全局。

数据目录沿用已落地约定；`data/` 与 `resources/` 尚未形成实现时，首次任务选一种并记录，不能双轨混用。禁止为十分钟课程游戏提前搭建通用 ECS、复杂事件框架或大量空目录。

### ENG-04 · 版本管理

提交源文件与必要导入配置，不提交 `.godot/` 和本机导出缓存；保留资源所需的 UID 与导入配置。单次改动聚焦一个可审查目标。用户任务已授权的必要共享文件变更可以执行并说明，不凭“需群里同步”自行向外发送消息。

## 3. 场景职责

| 模块 | 职责 | 边界 |
| --- | --- | --- |
| Player | 输入、移动、耐久、武器、交互入口 | 不直接硬编码所有关卡开门逻辑 |
| Enemy / Boss | 自己的预警、攻击、恢复、死亡 | 不管理整个游戏的剧情进度 |
| Room | 本房间入口、机关、敌人和重试 | 不清除全局探索记忆 |
| Interactable | 判断条件并执行明确效果 | 使用稳定 ID 记录状态 |
| HUD / Memory | 读取并展示数据 | 不代替游戏规则结算伤害 |
| Dialogue | 播放文本并通知事件结束 | 对话是否已看与世界效果分开管理 |

## 4. 跨场景状态建议

可使用一个小型 `GameSession` Autoload 管理本次对局需要跨场景保留的数据：

- 已获得武器 ID。
- 已探索区域 ID。
- 已读日志、已看剧情 ID。
- 已提交关卡进度与当前重试点。

敌人当前位置、弹丸、机关倒计时等属于房间运行状态，不全部塞进全局对象。房间重试按 03 的 STATE-01 恢复入口基线，成功跨房间后提交；具体规则已在本次修订中明确。保存已提交房间状态不等于保存弹丸、锁定和机关运行倒计时。

不为十分钟项目预先搭建复杂通用框架。优先使用少量清楚的场景、配置资源和信号。

## 5. 数据组织

- 武器参数使用两份配置资源，共用射击与投射物逻辑。
- 对话与日志统一选一种简单数据格式，避免一半 JSON、一半散落在脚本。
- 数据至少有稳定 ID；对话条目建议包含说话者、文本和必要事件标记。
- 日志 UI 只读取已发现 ID 对应的内容，不直接显示整个资源目录。
- 存档若以后加入，应基于稳定 ID 与必要状态，不能直接保存运行时节点引用。

## 6. 四人协作

- 沿用 README 中现有引擎与渲染约定；尚未确定的美术规格见 99。
- 每项任务明确模块、依赖和验收，不在本 Bible 擅自分配具体成员或排十周里程碑。
- 用独立场景组合关卡，避免多人同时覆盖一个大场景。
- 改共享配置、TileSet、输入、Autoload 和主场景时检查影响，保留其他成员工作；用户已授权的必要修改直接完成并说明，不擅自外发消息。
- 小步提交；按 03 的 QA 表选择相关检查，主线可运行后涉及主线变更应完整回归。未实现项目标尚不适用，不伪报通过。
- 文档与实现同步；已授权设计变化记录在 99，再同步相关模块，普通 bug 修复无需改设计规则。

## 7. 资产与试玩记录

`docs/asset_credits.md` 建议记录：文件路径、作者或来源链接、许可证、修改情况、必须署名的文本。占位素材应能一眼识别，替换后清理引用。

先一起确认基准分辨率、瓦片尺寸、角色画布与实际占地、碰撞尺寸、摄像机比例、像素缩放和过滤方式，再制作最终美术。复用地板、墙、管道与门，用区域专用装饰区分三个内部关卡。

- `docs/playtest_notes.md` 记录版本、试玩者、时长、死亡点、迷路点和修改结论。
- 机制变化先明确设计，再同步代码和相关 Bible 章节。
- 完成条件以能运行、能验证的行为描述，不以“写好了脚本”代替。
- 本目录结构仅为提案；如果调整路径，同时修改 README 和文档引用。
