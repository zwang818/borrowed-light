# 标题存档与继续游戏

标题提供一个本地旅程档案。「返回首页」和正常关闭游戏窗口都会自动保存当前关卡。图纸、制造、故事记录和管道解锁完成后也会自动保存。

## 玩家操作

- 没有有效存档时显示「开始旅程」。开场结束并进入腹腔后建立记录。
- 有有效存档时显示「继续旅程」。进入存档记录的关卡，从该关最近激活的灯塔恢复。尚未激活灯塔时使用对应入口或剧情安全落点。制造工坊从抵达管道旁继续。记忆档案中的「继续旅程」使用同一规则。
- 重新开始和删除需要确认。重新开始在抵达第一关后替换旧记录并清空内存中的成就。成就随游戏进程结束而清空。
- 正常关窗保存失败时留在游戏中并提示错误。强制终止程序时可从最近一次成功保存继续。
- 腹腔首战入口、脊柱暗道出口、脊柱检修观察区前的主走道和脊柱图纸台外的主走道各有一座存档灯塔。触碰脊柱的灯塔或面板都能保存。成功时指示灯亮起，屏幕上方显示「存档点已保存」。再次碰到另一座已亮的灯塔，也会把它设为最近一次的存档点。

## 现场快照与房间重试

版本 2 记录当前关卡、小一坐标与耐久、死亡状态、能力、选用武器、减速与攻击状态。首页继续时，小一按灯塔或安全落点重新定位，血量与关卡状态从最近一次成功保存的快照恢复。敌人按稳定 ID 恢复位置、耐久、死亡与当前行动阶段。存档还包括在途战斗弹丸、腹腔门禁及蛛网、脊柱入口防线与电弧相位。读到死亡现场时显示重试菜单。

未完成的对话、传输与交互演出可回到原处重新触发。界面、声音及装饰性动画按场景初始化。重试仍恢复房间入口的敌人和机关基线，并保留已解锁能力。腹腔出口转场期间保留腹腔现场，进入脊柱后更新为脊柱现场。

死亡菜单的重试优先使用本关已触发的灯塔。灯塔激活状态随旅程存档恢复，脊柱的旧返程复活点用于尚未碰到灯塔的旅程。暂停菜单的整关重开会把本关灯塔恢复成红色。

版本 1 档案继续支持，按原规则从相应关卡入口恢复。旧档中的图纸、能力、管道、探索与通关标记继续有效，下次成功保存时写入版本 2。

## 文件与恢复

默认路径为 `user://journey_save.json`。先写入并验证 `.tmp`，再保留上一份可读记录为 `.bak`。主文件损坏时可回退备份。主文件和备份都无效时，标题禁用读取。

存档使用 JSON 数据，校验版本、受支持的场景和快照结构。标题通过一次性的 `journey_session` 传递档案。直接运行 F6 或独立测试场景时，只有提供旅程会话或测试路径才启用保存。

## 第二关正式旅程（2026-11-17）

可选`spine_flow`保存首次倒下/开盖/图纸/已学维护回执/制造校准/有限压力与跨房间基线。`room=workshop`时标题继续恢复原腹腔制造场景；其余通关首关记录进入正式第二关。旧已解锁散射记录兼容保留能力。正式返程在菜单建立前确定旅程路径，独立 F6 使用空旅程路径，成就记录留在预览进程的内存中。异常目标加载/保存不提交源房间。详细边界见`spine_playable_flow.md`，本轮不修改Bible。

第二关故事与现场快照同时保留：`spine_flow`只承担已知剧情／能力／重试基线，当前位置、血量、敌人行动与弹丸仍使用版本2 `snapshot`。返程工坊保存为腹腔scene并由room字段恢复制造场景；跨区不套用来源地图快照，继续工坊在替换角色脚本之后恢复现场。新增验证包括`journey_snapshot_check.gd`的故事装置／门／压力恢复，以及`spine_flow_persistence_check.gd`真实待校准工坊的版本2继续。均在本轮提交副本复验通过，具体范围与退出清理限制见[第二关试玩](spine_playable_flow.md)。

## 并联清扫者

腹腔存档记住 Boss 是否停机、剩余耐久和清场协议进度。继续旅程时从存档点出发，回到出口房后恢复尚未结束的战斗。存档时正在执行的抓投、蛛网和震屏会清理，未完成的清场协议重新给出完整预警。已经获得终端通行资格的旧存档保留进度。Boss 战中死亡后选择重试，小一在出口房南侧门外满耐久复活，已经击败的清扫者保持停机。再次跨过门槛后，入口门关闭并开始一场满耐久的 Boss 战。从死亡界面返回标题后继续旅程，也可从这个位置重试。
