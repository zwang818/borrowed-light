# A · 第三关胸腔地图美术与照明

在 Godot 编辑器打开 `tests/manual/a_map/thorax_preview.tscn`，按 F6。入场使用第一关正式流程的跟随视角，缩放为 1.5 倍，镜头以小一脚底为跟随目标并在地图边界处限位。按 Tab 可同屏查看南侧落点与中央核心门。可在 `scenes/levels/thorax/thorax_graybox.tscn` 编辑地图。

| 操作 | 效果 |
| --- | --- |
| WASD／方向键 | 移动 |
| L | 在当前机位切换明亮检查和玩家暗场 |
| E | 靠近照明电闸拉闸。每只电闸只点亮自己连接的灯 |
| Tab | 切换全图和跟随镜头 |
| G | 查看碰撞、点位、候选范围和试走线 |
| R | 回到入口，恢复跟随镜头和区域断电 |

**明亮检查**展示未经环境压暗的甲板与设备细节。**玩家暗场**初始由核心门的暖白门环与蜜金反光指路。门环轻微闪烁，地板的反光随亮度起伏并分片闪动。门前实时灯也随门环变化，照到经过的小一。四组照明电闸拉下后各自锁定，灯具和附近的蜜金灯池亮起，设备实体对灯池产生遮光。切换检查模式保留已拉闸状态，R 恢复入场状态。

## 地图与素材

本版按概念图摆放南侧接收套筒、左侧配电筒组与设备岛、右侧检修吊架与设备列，以及北侧的封闭核心门和休眠总机。碰撞与遮光多边形按美术底座调整。吊架悬臂单独分层，角色从下方经过时会被臂端遮挡。中央开阔甲板及左右两侧均保留试走路线。1 格 = 32 世界单位，扣除实体占位的净地板约 **2393 格²**。

- `assets/sprites/environment/thorax/floor_tiles.png` 是独立生成的四格图集，含三种装甲钢板和一块通风格栅。用贴地材质绘制可编辑的甲板多边形，世界空间颗粒固定在一单位。各板磨损与色调按固定位置变化。
- `assets/sprites/environment/thorax/parts/` 包含独立生成并从图集中分出的六类透明精灵。配电筒组、配电站、设备岛、检修机架、吊架和核心门各自落位，材质与绘制顺序可单独调整。井壁、肋骨、平台包边和线缆由 `thorax_structure.gd` 分层绘制。
- 图集和设备精灵使用内置 imagegen 生成。钢板图集提示要求正俯视、四个等大方格、三种兼容磨损程度和一个深色格栅。设备图集提示以第一关素材的硬像素边缘为质感参考，按胸腔概念图的设备类型与靛蓝配色生成分开的透明部件。
- 核心门框与门扇使用独立精灵，门环、随时间闪动的地板倒影和 `Lighting/CoreSpill` 实时光源分别绘制。四组局部灯的开关壳体和拉柄也独立于设备纹理。
- `Floors/Deck` 同时负责甲板纹理裁切、地板碰撞边界和周界遮光。 `Facilities` 的十个实体各自有独立碰撞和遮光。
- `Lighting` 提供 `pull_switch(world_position)` 和 `switch_pulled(switch_id)`，供正式玩家接入自己的交互输入。 `set_inspection_mode` 用于查看美术，`reset_lighting` 恢复区域断电。
- `Markers` 保留原有稳定 ID，包含四组电闸和灯位、双插槽、总机、候选重试点以及核心转场点。核心门现阶段为封闭实体，正式门禁、桥片与总机行为由队友接入。参见 [Bible 第 6 节](bible/09_level_flow.md#6-第三关胸腔)。
