## A 暖灰旧钢配色（2026-11-14）

当前灰盒使用 `head_16dir_a.png` 和 `pedestal_a.png`，原版保留供对照。内置 imagegen 以原十六方向图/底座为编辑目标、用户选定 A 概念图为配色参考生成透明 PNG。仅 B 灰盒引用；正式场景未同步。

提示词：保持原画布、轮廓、比例、十六方向 4×4 排列、帧中心与炮口位置；采用暖灰旧钢、低饱和旧铜、灰米白条纹与少量暗锈，去除金色高光；统一左上柔和亮面、右下暗面和凹槽阴影，简化细碎纹理；保留红眼；底座只含托盘立柱，无背景、文字、外部投影，保留透明通道。

引擎另绘制两层暖色底座接触阴影，以及随悬浮高度轻微改变宽度和透明度的托盘内球体阴影。模型大小、碰撞、攻击参数和镜头不变。

验证：Godot 导入完成；floating_sentry_check、sentry_alternating_check 均 PASS。实际渲染第二关四个朝向检查材质、透明边缘和遮挡；测试退出仍有既有 ObjectDB/resource 警告，沙箱有用户日志/编辑器设置及证书权限提示。

生成提示词要点：保持参考的灰绿旧金属、掉漆米白条纹、黄铜与锈迹、像素风、同一俯视斜角；底座只绘制托盘立柱，移除球体；球体图只绘制八个一致比例的水平朝向，保留红眼和单炮口，背面遮挡红眼炮口，无支架、文字、背景或阴影。

渲染使用最近邻采样。后方炮口锚点按球体遮挡估计；八方向是当前试做精度，并非连续3D模型。PNG保留生成的透明度，未使用色键抠图。
