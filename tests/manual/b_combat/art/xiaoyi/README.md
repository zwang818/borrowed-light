# 小一像素风基础形态

依据用户暂定的第二版废土机器人概念制作：蓝绿旧漆、米白面板、青色发光圆眼、黄色右肩护甲、背包、外露机械关节。

- `xiaoyi_idle_pixel.png`：透明背景 PNG，1227 × 1282，单帧像素风原图。不是原生 96 × 96 精灵表，也不是骨骼或三维模型。
- `xiaoyi_pixel.tscn`：可独立实例化的展示节点，最近邻过滤，显示高度约 64 px；无脚本、碰撞、输入或攻击逻辑。
- 预览入口：`res://tests/manual/b_combat/xiaoyi_pixel_preview.tscn`，Godot 打开后按 F6，对照放大外观与游戏尺寸。

基础预览为双手尚未进化形态。`xiaoyi_laser_pixel.png` 保留为早期左臂激光单帧参考；当前通过灰盒专用 `xiaoyi_combat_visual.gd` 将下述三套动作图集接入 `combat_test.tscn`；未修改共享玩家、主场景或 AB 场景。

战斗使用三套八方向、每方向四帧图集：

- `xiaoyi_laser_8dir.png`：数字 1，左臂持续举起的激光姿态。
- `xiaoyi_unarmed_8dir.png`：数字 2，双手放下，不攻击。
- `xiaoyi_scatter_8dir.png`：数字 3，右臂持续举起的散弹姿态。

展示高度约 64 px。武装时身体朝鼠标，无武器时身体朝实际移动方向，停止保向。迈步帧按移动距离推进，转身经过相邻方向，不镜像交换左右手。脚底箭头指最近的存活敌人，无目标时隐藏，不代表瞄准或自动改变射击方向。

`combat_player.gd` 继承共享玩家，仅用于灰盒。两种能力直接开放供测试；忙碌时不切换、不排队输入。散弹采用 Bible 原型参数：三颗、24°、0.75 秒、128 px 射程、448 px/s，每颗 1 伤害为测试值。碰墙或敌人消失、每颗只结算一次。R 清理弹丸并重置测试。共享场景、主场景、AB 和公共 Input Map 未修改。

图集仍是生成的原型动作素材，未做逐像素精修、连续角度手臂瞄准或进化演出。角色身体采用八方向表示鼠标方向；激光射线保持原有精确方向、锁向和碰撞规则，身体转向不会改变已发射光束。发射前先检测身体到枪口的遮挡；无遮挡时激光从左臂枪口、散弹从右臂枪口开始。枪口坐标通过 `muzzle_points.json` 按模式、朝向、动作帧记录，并跟随脚底对齐和显示缩放。身体与枪口之间有墙或敌人时在近侧结算，不从障碍另一侧生成攻击。蓄力光效也跟随左臂枪口。

验证入口：`xiaoyi_animation_check.gd` 与 `attack_modes_check.gd`，覆盖方向、迈步、停止、三模式、禁攻、冷却、最近敌人更新、散弹单次命中和阻挡。

三套动作图通过内置 image_gen 生成：参考现有 4 列 × 8 行图集，保持身体身份和行走帧，分别绘制左臂抬起、双臂放下、右臂抬起姿态；输出透明底，保持八朝向与左右臂身份。额外修正激光前后视图手臂位置。图集采用测量后的行间隔裁取并对齐脚底。

生成方式：内置 image_gen，以第二版概念图为参考。生成提示要求：保留上述身份特征，单个全身角色、略俯视三分之四正面、普通机械双手、透明背景、清晰阶梯状轮廓、简化锈迹和像素色块，无文字、地面或武器特效。生成结果是高分辨率像素风素材，正式低分辨率动画仍需进一步制作。

## 移动残影修复

迈步与转向更新改为在玩家移动之后的物理帧执行；渲染帧只抵消父节点旋转，避免高刷新率下零位移渲染帧将行走反复重置为站立。加载时保留每帧主要连通区域，清除误裁入的邻帧碎片和低透明度杂边；只生成运行时纹理，不改原 PNG。回归检查覆盖 240 Hz 渲染／60 Hz 物理节奏及碎片过滤。

## 三个朝向的手臂归属修正

散弹右侧面／右前斜向（行 6、7，零起始）和激光右后斜向（行 5）使用 `xiaoyi_scatter_handedness.png` / `xiaoyi_laser_handedness.png` 的对应行。只替换这十二帧，其他行仍使用原图集；不会通过整体镜像修正手臂。对应枪口坐标已同步更新，攻击参数和输入逻辑不变。

修正素材由内置 image_gen 按原图编辑：散弹改为可辨认的右肩—肘—散弹装置连接；激光右后视图改为左肩抬起、右手放下，并调整前后遮挡。保留四列动作、原身份和透明底；加载器只采用指定行，隔离其他生成差异。
