# B 灰盒战斗音效

依据 Bible `06_audio.md` 的 AUDIO-01 / ASSET-01。本轮仅 B 场景挂载 `../combat_audio.gd`；没有修改共享玩家、武器、敌人脚本，也没有修改或同步 `ab_test`。

## 来源

新增 17 个 WAV 为 Codex（OpenAI AI 编程助手）编写 `generate_sounds.py` 后，以数学振荡器、固定随机种子的噪声及包络合成的原创**原型占位音效**。无第三方录音、采样、模型生成音频或外部素材，无第三方署名要求；不冒称真人录制或专业音效成品。Python 标准库即可重建，执行 `python3 tests/manual/b_combat/audio/generate_sounds.py`。

44.1 kHz、16 位、单声道、无循环；各文件采样峰值统一为 0.3，起止渐变避免硬切。现有脉冲蓄力/激光继续使用 `assets/audio/` 原资源，本次未修改。

## 播放与验收

- 新音效最多 8 个并发，同种声音 70 ms 内合并。脚步低于普通命中/击发，玩家受伤和危险预警优先。原有脉冲枪两路播放器独立保留。
- 暂停清除新增声音并停止现有脉冲音；恢复不补播旧事件。R 重试停止声音并重新采样状态，场景卸载随节点清理。
- 保留原有闪烁、生命条、攻击区域和预警视觉，声音不会替代危险提示。
- 自动检查：`godot --headless --path . --script res://tests/manual/b_combat/audio_check.gd`。覆盖无敌帧、密集命中合并、预警转攻击、死亡、脚步、重试、暂停恢复与并发上限。
- 2026-10-21：导入、场景启动和事件/清理检查通过。最终听感及不同耳机/扬声器音量平衡仍须人工试听；不将自动检查称为听感验收。

### 移动音效调整（2026-10-21）

按试玩反馈，将脚步改为 120 ms 的柔和机械触地声，去除宽频噪声与硬起音；播放增益从 -17 dB 降至 -25 dB。移动触发距离不变，其他音效及 AB 整合场景不变。单独重建：`python3 tests/manual/b_combat/audio/generate_sounds.py player_step`。最终舒适度待玩家试听确认。

### 清脆金属脚步（2026-10-21，替代上一版柔和脚步）

按用户明确反馈“金属地板上的清脆声；上一版太闷、不自然”，改为短促接触声与非整数倍金属板共振，余音快速衰减，移除原先低沉的软触地音色。保持 -25 dB 播放增益；四步轻微音高变化减少重复感，复用播放器时其他声音恢复原音高。仅重建 player_step.wav，不修改 AB 或其他声音素材。自动检查不代表人工听感已确认。

### 金属格栅脚步（替代前述音色）

用户选择：去掉电子提示音感，机器人踩金属格栅，带摩擦与零件轻响，音量适中。脚步改为非周期滤波噪声的多层短冲击、摩擦与延迟轻碰，去掉固定频率振荡器。生成四个独立接触变化版本 player_step.wav / player_step_2.wav / player_step_3.wav / player_step_4.wav，逐步轮换，不再只改变音高。播放增益 -19 dB，低于普通攻击的 -11 dB 与受伤的 -5 dB。只重建脚步素材；仍属程序合成占位声音，并非真实录音，听感待用户确认。

用户试听后要求移动声再小一点：脚步播放增益由 -19 dB 调至 -22 dB，音色、节奏和其他音效不变，仅影响 B 灰盒。
