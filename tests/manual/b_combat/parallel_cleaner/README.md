# 《借光》并联清扫者 · 腹腔出口可玩原型

打开 `abdomen_boss_playtest.tscn`，在 Godot 按 **F6**。原型继承正式腹腔地图和已有双蜘蛛战，起点设在出口战前，左臂脉冲已校准。使用正式场景的操作绑定（默认 WASD／方向键、鼠标瞄准、左键攻击、E 交互）。**B** 跳过双蜘蛛直接合体，**R** 重试，**O** 显示底盘、双壳、实心下缘、路线和脉冲首接触点，并在 Godot 输出状态变化。死亡时可用重试菜单。此入口使用单独的试玩成就文件，不读取正常旅程。

| 环节 | 试玩表现 |
| --- | --- |
| 双蜘蛛 | 一只吐丝牵制退路，另一只绕设备。两只都停机后才启动并联处置，击败顺序不限。 |
| 残骸回收 | 回收索拉拢两具残骸，合壳撑腿起身。此时可以走位，合体动作不伤害玩家。 |
| 吐丝与收线 | Boss 在选中吐丝的同一帧锁向并发射。蛛丝沿锁定方向飞行，撞到掩体近侧即铺网。命中小一才减速和收线，掩体仍能断丝。 |
| 实体底盘和侧探卡位 | 合体后等落点净空才启用底盘。借设备断丝或正面追击受阻时，用完整底盘检查设备两侧。探足和落脚跟转不移动，第三帧物理横移，第四帧站稳；途中封路会停下重新选路。 |
| 收线与抓投 | 收线速度 230 单位/秒，最近停在 48，最多拉 190 或持续 1.05 秒。距离到 72 时锁向并启动原有 0.30 秒抓投预警。小一仍可横移出扇区。预警完整、实际拉近至少 16 单位且夹击有效才抓投。遮挡、身体撞障碍、拉距到顶或超时都会立即脱线。打空后收招 0.08 秒，脱线后收招 0.24 秒，随后逼近、换边或择招。 |
| 抓投表现 | 抓中后在各帧的钳口插槽绘制小一、扣锁火花和前钳遮挡。扣紧 0.04 秒，举住 0.18 秒，随后从上一拍的躯干位置松钳。正常扫掠飞行 0.33 秒、约 87 单位；从实际位移选八方向，撞停不改朝向。真实落点显示 0.15 秒擦地姿势和按连续角度旋转的擦痕；墙面同时缩短及裁切擦痕。落地一次扣 1 点并立即归还操作。 |
| 右钳宽扫 | 普通交战使用宽扫和重砸。贴身或脱线后，短夹有合法角度时也可出招。横穿时优先宽扫，候选距离 45–85、横扫半径 85，预警、光刃和判定共用范围。常态冷却 1.95 秒，前摇 0.32 秒（红怒约 0.26 秒）。第 3 帧启动光刃，第 4 帧对齐光刃并一次扣 2 点。 |
| 闭钳重砸 | 66–105 单位检查是否能从当前站位砸到小一。第 6 帧的钳口锚点固定落点，常态预警约 0.55 秒，落地圈半径 60。第 6 帧一次扣 3 点，并启动 29 帧冲击和 3 像素镜头抖动。动作停 0.05 秒，镜头在 0.18 秒内归零。常态冷却 4.4 秒，收线或抓投释放后 1 秒内不接重砸；砸空后另有 0.93 秒可反击。横扫或重砸致死时，先播放 0.23 秒接触反馈，再打开死亡菜单。 |
| 追击与残丝 | 常态追击 130 单位/秒，红怒 156；侧移和退步按追击速度的比例变化，步态随实际位移推进。小一在战区里时，Boss 可以从画面外靠近，入画后才出招。无遮挡且距离小于 128 时优先追近；隔着掩体时可先吐丝封路。吐丝射程 400、飞速 620，中心线两侧各 25 单位可捕获，弹道在墙面截断。发射时计入 2.65 秒冷却，打空落地时将剩余冷却缩到最多 0.90 秒。小一离场后 Boss 回守。每张落地残丝独立留存 30 秒，不设数量上限；半径 50、移速倍率 0.74，重叠不叠乘。 |
| 耐久与红怒 | 20 点耐久，单束有效脉冲扣 1 点；头顶每格 1 点，10 点处有分隔。剩 10 点或以下时机体和亮格变红，从下一次出招起，预警与攻击动画以 1.25 倍速度播放；冷却同时加快。红怒不增加伤害，也不会打断已经开始的预警或缩短砸空后的反击窗口。 |
| 终端和重试 | 融合体停机才打开终端区域入口；终端按原流程上电并输入 `0417`，抵达出口结束原型。重试清除蛛丝、抓取、回收索和 Boss，双蜘蛛复位。 |

`art/` 含原有 12 张 ImageGen 动作帧；`art/actions/` 保留侧探和短夹的 8 张 PNG。双壳姿势保持原脚点（100，122），绞盘按 `anchors.json` 对齐。测试房的 `boss_art_scale` 默认 0.85。短接触影独立居中于脚点，可见部分约 56×19。右钳扫击与光刃见 `art/right_claw/` 和 `art/claw_sweep_fx/`；下砸 8 帧、脚点与撞点清单、阴影、地网和冲击图集及许可都在 `art/ground_actions/`。素材均采用最近邻采样。

### 测试房碰撞

| 对象 | 层 | 掩码／判定 |
| --- | --- | --- |
| Boss 底盘 | 9（256），合体后开启 | 1（墙、设备、关闭的门）及 10（小一脚底）；默认 61.2×30.6 的横向胶囊，无接触伤害 |
| 小一的脚底 | 原层 2，附加 10（512） | 原掩码 1，附加 9；原背后的角色受击代理仍只在层 2 |
| Boss 背壳／实心下缘 | 3（4），两个独立受击 Area2D | 下缘的横梁和靠前腿根各自贴形，共用 Boss 的伤害接收器；脚尖、影子与腿间空隙不计受击 |
| 脉冲／钳口 | 无物理层 | 脉冲查 1＋3，首接触点同时用于主光束、核心线和火花；钳口只按锁向、距离和世界层遮挡结算 |

在 Godot 的「调试 → 可见碰撞形状」开启轮廓后按 F6。`encounter_check.gd` 覆盖落点净空、墙／设备／关门、窄缝、双方阻挡、侧路、中途封路和原有战斗、终端及重试。`tuning_check.gd` 覆盖基础射线、宽扫和追击。`ground_actions_check.gd` 覆盖四种姿态射线、横穿选招、残丝与重砸；设置 `PARALLEL_CLEANER_CAPTURE` 并使用渲染窗口时，可保存 30 FPS 的检验帧序列。层 9 和 10 只由测试房脚本配置。

`art/grab_throw/` 含四帧抓投、前钳遮挡、小一被夹帧及两套八方向图集、PixelFX 抓取和擦地源码的许可及图集。运行 `throw_check.gd` 可验证正上、正下、左上、右下、撞止、抓空和实际收线后重试；同样支持 `PARALLEL_CLEANER_CAPTURE`。

`web_reel_check.gd` 验证即时发射、弹道、打空后追击与再发射、拉距、设备断丝、拉动碰撞、超时、近身横移躲抓、贴身选招和重试。按 **O** 后，输出窗口的 Boss 状态行会记录剩余时间、吐丝结果、脱线原因、实际拉距和退步原因。

### 素材来源

- `art/pose_*.png` 为本项目原型生成的并联清扫者动作。`art/actions/`、`art/right_claw/`、`art/ground_actions/` 和 `art/grab_throw/` 中的角色帧及锚点来自本项目的侧探与短夹、右钳横扫、重砸与落地残丝、抓投动画与特效素材包。
- 光刃、砸地、蛛丝、扣锁和擦地的 PixelFX 图集及帧数据随原许可和署名一同保留，见 [光刃](art/claw_sweep_fx/NOTICE.md)、[重砸和残丝](art/ground_actions/NOTICE.md)及[抓投](art/grab_throw/NOTICE.md)。
