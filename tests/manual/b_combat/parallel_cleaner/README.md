# 《借光》并联清扫者 · 腹腔出口可玩原型

打开 `abdomen_boss_playtest.tscn`，在 Godot 按 **F6**。原型继承正式腹腔地图和已有双蜘蛛战，起点设在出口战前，左臂脉冲已校准。使用正式场景的操作绑定（默认 WASD／方向键、鼠标瞄准、左键攻击、E 交互）。**B** 跳过双蜘蛛直接合体，**R** 重试，**O** 显示底盘、双壳、实心下缘、路线和脉冲首接触点，并在 Godot 输出状态变化。死亡时可用重试菜单。此入口使用单独的试玩成就文件，不读取正常旅程。

| 环节 | 试玩表现 |
| --- | --- |
| 双蜘蛛 | 一只吐丝牵制退路，另一只绕设备。两只都停机后才启动并联处置，击败顺序不限。 |
| 残骸回收 | 回收索拉拢两具残骸，合壳撑腿起身。此时可以走位，合体动作不伤害玩家。 |
| 吐丝与收线 | Boss 在选中吐丝的同一帧锁向并发射。蛛丝沿锁定方向飞行，撞到掩体近侧即铺网。命中小一才减速和收线，掩体仍能断丝。 |
| 实体底盘和侧探卡位 | 合体后等落点净空才启用底盘。借设备断丝或正面追击受阻时，用完整底盘检查设备两侧。探足和落脚跟转不移动，第三帧物理横移，第四帧站稳；途中封路会停下重新选路。 |
| 收线与抓投 | 收线速度 230 单位/秒，最近停在 48，最多拉 190 或持续 1.05 秒。固定出丝口到小一的绑定点决定丝路是否畅通。遮挡或擦碰进入 0.12 秒松线，暂缓拉动与抓投预警，总计时继续。丝路与实体步进恢复就续拉，持续遮挡、到顶、超时或离场则脱线。距离到 72 时锁向并启动原有 0.30 秒抓投预警，小一仍可横移。预警完整、实际拉近至少 16 单位且夹击有效才抓投。打空后收招 0.08 秒，脱线后收招 0.24 秒，随后逼近、换边或择招。 |
| 抓投表现 | 抓中后在各帧的钳口插槽绘制小一、扣锁火花和前钳遮挡。扣紧 0.04 秒，举住 0.18 秒，随后从上一拍的躯干位置松钳。正常扫掠飞行 0.33 秒、约 87 单位；从实际位移选八方向，撞停不改朝向。真实落点显示 0.15 秒擦地姿势和按连续角度旋转的擦痕；墙面同时缩短及裁切擦痕。落地一次扣 1 点并立即归还操作。 |
| 右钳宽扫 | 普通交战使用宽扫和重砸。贴身或脱线后，短夹有合法角度时也可出招。横穿时优先宽扫，候选距离 45–100、横扫半径 100、扇形总角 180°，预警、刀刃、裂隙和判定共用范围。常态冷却 1.95 秒，前摇 0.32 秒（红怒约 0.26 秒）。第 3 帧启动空间裂隙，第 4 帧对齐满刃并一次扣 2 点。实际扣血才定格约 67 毫秒，小一仍可操作。错位局限在裂隙遮罩内，最大 4 个游戏画布像素。 |
| 横扫增压 | 收钳后双壳灯带同步亮起 3 秒，普通近战攻速提升 18%，追击和侧移速度提升 20%。命中和挥空都可触发，再次完成横扫刷新时间。出招时锁定倍率，叠加红怒时总攻速封顶 1.35 倍。重砸预警和砸空反击时间照旧。 |
| 闭钳重砸 | 66–105 单位检查是否能从当前站位砸到小一。第 6 帧的钳口锚点固定落点，常态预警约 0.55 秒，落地圈半径 60。第 6 帧一次扣 3 点，并启动 29 帧冲击和 3 像素镜头抖动。动作停 0.05 秒，镜头在 0.18 秒内归零。常态冷却 4.4 秒，收线或抓投释放后 1 秒内不接重砸；砸空后另有 0.93 秒可反击。横扫或重砸致死时，先播放 0.23 秒接触反馈，再打开死亡菜单。 |
| 追击与残丝 | 常态追击 130 单位/秒，红怒 156。近身优先选招或侧移；路线受阻后立即换路，绕压缩机的路径受限时会搜索其他可走路径。小一离场后 Boss 跟到战区边缘。Boss 入画且目标在战区内才会出招。吐丝射程 400、飞速 620，中心线两侧各 38 单位可捕获，弹道在墙面截断。发射时计入 2.65 秒冷却，打空落地时将剩余冷却缩到最多 0.90 秒。吐丝命中小一时，会在命中的脚下位置留一张固定残网。每张残网半径 50，独立留存 30 秒，场上最多同时存在 10 张。生成新网时若已满，移除最早生成的那张。每层减速 26%，按覆盖层数相加，最多减速 80%。离开一张网或该网到期时，立即按剩余层数重算。Boss 的底盘中心踩在自身任一残网内时，追击和侧移速度乘以 1.20，重叠残网只加速一次。这项加速可以与横扫增压同时生效，墙体仍会截断残网覆盖。 |
| 重复露头 | 瞄准压缩机墙角露头，5 秒内被两束独立脉冲从同一角实际命中后，Boss 收完当前动作再绕向对侧出口。只用命中时的可见位置和底盘可通行路线选点。旧露头口有合法落点且能确认小一留有干净退路时，可先吐丝铺网。到达对侧并重新看见小一后，按原时序预警横扫或重砸。 |
| 耐久与红怒 | 20 点耐久，单束有效脉冲扣 1 点；头顶每格 1 点，10 点处有分隔。剩 10 点或以下时机体和亮格变红，从下一次出招起，预警与攻击动画以 1.25 倍速度播放；冷却同时加快。红怒不增加伤害，也不会打断已经开始的预警或缩短砸空后的反击窗口。 |
| 清场协议 | 首次降到 10 点耐久或以下且仍存活时排队。当前招式结束、小一恢复操作并在出口战区内时起手。Boss 原地扎足，整个出口战斗房落在两拍地震内。青绿色缺口宽 20°，起手时优先在可走到的侧面或背后随机选择，两拍共用同一位置。墙角或蛛网限制走位时，缺口仍会落在能及时到达的位置。闭钳举高时避开钳尖标出的近圈。整套默认最多一次实扣 2 点耐久。 |
| 终端和重试 | 融合体停机才打开终端区域入口；终端按原流程上电并输入 `0417`，抵达出口结束原型。重试清除蛛丝、抓取、回收索和 Boss，双蜘蛛复位。 |

`../../../../assets/sprites/enemies/parallel_cleaner/` 含原有 12 张 ImageGen 动作帧；`../../../../assets/sprites/enemies/parallel_cleaner/actions/` 保留侧探和短夹的 8 张 PNG。双壳姿势保持原脚点（100，122），绞盘按 `anchors.json` 对齐。测试房的 `boss_art_scale` 默认 0.85。短接触影独立居中于脚点，可见部分约 56×19。右钳动作与新版裂隙见 `../../../../assets/sprites/enemies/parallel_cleaner/right_claw/` 和 `../../../../assets/sprites/enemies/parallel_cleaner/sweep_rift_v2/`；下砸 8 帧、脚点与撞点清单、阴影、地网和冲击图集及许可都在 `../../../../assets/sprites/enemies/parallel_cleaner/ground_actions/`。素材均采用最近邻采样。

### 测试房碰撞

| 对象 | 层 | 掩码／判定 |
| --- | --- | --- |
| Boss 底盘 | 9（256），合体后开启 | 1（墙、设备、关闭的门）及 10（小一脚底）；默认 61.2×30.6 的横向胶囊，无接触伤害 |
| 小一的脚底 | 原层 2，附加 10（512） | 原掩码 1，附加 9；原背后的角色受击代理仍只在层 2 |
| Boss 背壳／实心下缘 | 3（4），两个独立受击 Area2D | 下缘的横梁和靠前腿根各自贴形，共用 Boss 的伤害接收器；脚尖、影子与腿间空隙不计受击 |
| 脉冲／钳口 | 无物理层 | 脉冲查 1＋3，首接触点同时用于主光束、核心线和火花；钳口只按锁向、距离和世界层遮挡结算 |

在 Godot 的「调试 → 可见碰撞形状」开启轮廓后按 F6。`encounter_check.gd` 覆盖落点净空、墙／设备／关门、窄缝、双方阻挡、侧路、中途封路和原有战斗、终端及重试。`tuning_check.gd` 覆盖基础射线、宽扫和追击。`ground_actions_check.gd` 覆盖四种姿态射线、横穿选招、残丝与重砸；设置 `PARALLEL_CLEANER_CAPTURE` 并使用渲染窗口时，可保存 30 FPS 的检验帧序列。层 9 和 10 由腹腔出口战斗脚本配置，独立测试房复用同一配置。

`../../../../assets/sprites/enemies/parallel_cleaner/grab_throw/` 含四帧抓投、前钳遮挡、小一被夹帧及两套八方向图集、PixelFX 抓取和擦地源码的许可及图集。运行 `throw_check.gd` 可验证正上、正下、左上、右下、撞止、抓空和实际收线后重试；同样支持 `PARALLEL_CLEANER_CAPTURE`。

`web_reel_check.gd` 验证即时发射、加宽后的弹道、打空后追击与再发射、拉距、设备断丝、拉动碰撞、超时、近身横移躲抓、贴身选招和重试。按 **O** 后，输出窗口的 Boss 状态行会记录剩余时间、吐丝结果、脱线原因、实际拉距和阻挡对象。

追击和预警共用地图的 `ExitCombat` 区域，Boss 的移动边界按底盘尺寸内缩。`arena_check.gd` 开启 **O** 后记录小一脚底坐标和 `in_arena`，检查左墙、底墙、墙角、掩体后方和入口走廊。`web_reel_check.gd` 还覆盖松线后续拉、持续遮挡、固定出丝口、松线中的总时限和离场。

队友可先在压缩机同一个角露头，5 秒内打中两束脉冲，再换到另一边引出重砸。看见落点圈后侧移，趁 0.93 秒的砸空收招充能反击。`peek_check.gd` 覆盖 5 秒记忆、同侧命中、墙后移动、对侧受阻换点、封网退路检查和完整重砸反击。

`rift_sweep_check.gd` 覆盖接触帧同步、实际扣血定格、挥空、墙体裁切、增压速度与清理。设置 `PARALLEL_CLEANER_CAPTURE`，使用渲染窗口及 `--fixed-fps 60` 可保存四段 60 FPS 原比例画面。横扫停表时间、最大错位幅度取自素材 JSON，增压时长、倍率和叠加上限在 `boss.gd` 中。

### 清场协议

按 **B** 快进到合体，用脉冲把 Boss 打到半血。起手的青绿色扇区可以避开两拍地震。缺口从小一能用普通移动及时抵达的方向中随机抽取，并按现有蛛网可能造成的减速预算走位时间。没有可达侧路时，缺口对准小一当前可站的位置。只有不侵入缺口与已验证通路的落点才会铺网。

| 动作时间 | 场内表现 |
| --- | --- |
| 0.00／0.38 秒 | 锁定脚底、朝向和缺口。灯带先后亮起，缺口两侧落丝。 |
| 0.90／1.00／1.35 秒 | 开始播放地震。近震覆盖脚底 150 单位内，外震扫过其余房间，按起手位置推到出口战区最远的墙角。预警和地震图集统一按房间边界裁切。外震只有进入外圈预警带才有伤害。两拍地震可穿过墙体与设备，受出口战区边界限制。地面纵向比例为 0.68。 |
| 1.47／1.58 秒 | 切到高钳图集，枢轴仍落在同一脚点。终砸预警取钳尖在墙前的合法触地点，冲击以半径 80 穿墙传播，出口战区与安全缺口仍限制判定。 |
| 2.00／2.62 秒 | 终砸锁在该点，接上原有暗铜冲击。触地后留 0.62 秒反击时间，再恢复红怒追击。 |

两拍震屏沿用图集附带的 60 FPS 位移，HUD 留在原位。实际扣血才停表 67 毫秒。碰到无敌帧时还可以由下一拍消耗伤害额度。测试房根节点的 `clearance_damage` 控制伤害。**R** 会重建 Boss、清理残网、动作和相机偏移。

`clearance_check.gd` 在同一试玩场景验证阈值、吐丝与抓投排队、三种首次命中、波前、左右脚点、三次穿墙命中、整间出口战区覆盖、随机缺口走位和重试。设置 `PARALLEL_CLEANER_CAPTURE` 后用渲染窗口搭配 `--fixed-fps 60` 可保存左右两段验收画面。
